BEFORE YOU START

Three things to have ready.

01

Your placement

A GumGum zone ID and slot ID, supplied by your GumGum team.

02

Your website

Access to your site’s scripts and a place to host the Exit Ads file.

03

Your Prebid setup

An existing Prebid.js bundle that includes the GumGum bid adapter.

01

INSTALL

Add Exit Ads to Prebid.

Download the publisher package and host exit-ads.min.js with your site’s JavaScript assets. It runs alongside your existing Prebid.js bundle and uses the gumgumBidAdapter to request ads.

Download publisher package ↓

A ready-to-use companion script. No build step required.

↳

The package does not include Prebid.js. Check that your existing bundle includes the GumGum bid adapter before connecting Exit Ads.

02

CONFIGURE

Decide when your brand appears.

Choose the moments you want, set their timing, and control how often an ad can appear. Add your GumGum placement IDs, then copy or download the configuration.

Build your configuration →

The configuration starts with the module’s defaults. The showcase’s 45-second timer is an illustration; the module defaults to 60 seconds.

03

CONNECT

Bring it onto the page.

Save the generated configuration as exit-ads-config.js. Load Prebid, the Exit Ads companion script, and your configuration in that order. No separate initialization call is needed.

HTML 
<!-- Use your own file paths. Keep this loading order. -->
<script src="/js/prebid.js"></script>
<script src="/js/exit-ads.min.js"></script>
<script src="/js/exit-ads-config.js"></script>

If your page already loads Prebid, add the companion script and configuration immediately afterward; load Prebid only once. Avoid async loading here so the companion is ready before configuration runs.

↳

Use your own placement IDs and ad sizes. The Doritos artwork in the showcase is an example; your winning bid supplies the live creative.

04

VERIFY

See the real experience.

On a test page, perform one of your enabled moments. You can also request an ad directly after Prebid has loaded:

JAVASCRIPT 
// Run on your configured test page.
window.pbjs.que.push(function () {
  window.pbjs.exitAds.trigger();
});
  • Confirm an eligible winning bid renders in an overlay.
  • Check that the close countdown matches your setting.
  • Close the ad and confirm the page remains usable.
  • Check repeat timing and page, session, and daily caps.

No eligible bid means no ad. Check placement IDs, ad sizes, available demand, and your site’s consent setup. Manual requests also respect frequency limits and the minimum 30-second gap after a successful display or close.
